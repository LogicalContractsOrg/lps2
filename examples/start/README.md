# Start here — the shortest way in

The five programs the tutorial and the start page open: `goat_declarative.pl`
(a puzzle stated rather than solved, with its expected trace `.lpst`),
`blocks.lps` (a tower rebuilt, drawn in 2D), `blocks3d.lps` (the same in 3D),
`lights.lps` (a picture you can click, in a live session) and
`thermostat.lps` (a program that never ends).
