# Agentic AI Runtime Governance

The FIX AI Working Group's traffic-light (Green / Amber / Red) runtime-governance scheme, expressed as computable policies over an agent's execution trace.

The 21 policies of the Ponens pack `agentic-ai-runtime-governance`, as a program of Logical English for LPS: each policy is a law that records a breach, and each of the 14 traces under `sources/traces/` is a scenario. Choose a scenario and press **Run**: the breaches are on the timeline, at the step where each policy failed, and the comment above each scenario says what Ponens's own evaluator found on the same trace.

Ledger: 21 policies encoded, 0 kept as residue (formulas Ponens's own parser cannot read).

The pack is Imandra's reading of: FIX AI WG — Proposal on Agentic AI Runtime Governance (Healey & Houston, Jun 2026); Szpruch, Sudjianto, Bhatti & Ang (2026).
