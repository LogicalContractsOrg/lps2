# NIST SSDF (Secure Software Development)

The NIST SSDF (SP 800-218) secure-development practices — Prepare the Organization, Protect the Software (integrity/provenance), Produce Well-Secured Software, Respond to Vulnerabilities — as computable policies over a development/release trace.

The 14 policies of the Ponens pack `nist-ssdf`, as a program of Logical English for LPS: each policy is a law that records a breach, and each of the 2 traces under `sources/traces/` is a scenario. Choose a scenario and press **Run**: the breaches are on the timeline, at the step where each policy failed, and the comment above each scenario says what Ponens's own evaluator found on the same trace.

Ledger: 14 policies encoded, 0 kept as residue (formulas Ponens's own parser cannot read).

The pack restates: NIST SP 800-218 SSDF v1.1.
