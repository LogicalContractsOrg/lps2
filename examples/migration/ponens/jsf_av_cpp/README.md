# JSF Air Vehicle C++

The JSF++ (F-35) C++ compliance process — Shall/Will/Should categories, tiered deviation approval, verification, and safety-critical library/run-time obligations — as computable policies.

The 12 policies of the Ponens pack `jsf-av-cpp`, as a program of Logical English for LPS: each policy is a law that records a breach, and each of the 2 traces under `sources/traces/` is a scenario. Choose a scenario and press **Run**: the breaches are on the timeline, at the step where each policy failed, and the comment above each scenario says what Ponens's own evaluator found on the same trace.

Ledger: 12 policies encoded, 0 kept as residue (formulas Ponens's own parser cannot read).

The pack restates: JSF Air Vehicle C++ Coding Standards (Lockheed Martin, Rev C, 2005).
