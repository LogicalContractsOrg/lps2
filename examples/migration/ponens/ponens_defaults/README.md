# Ponens's own policies

The policies of Ponens that belong to no pack: how an AI coding agent should work (read before editing, test before committing, prove before a high-stakes change).

The 39 policies of the Ponens pack `ponens-defaults`, as a program of Logical English for LPS: each policy is a law that records a breach, and each of the 8 traces under `sources/traces/` is a scenario. Choose a scenario and press **Run**: the breaches are on the timeline, at the step where each policy failed, and the comment above each scenario says what Ponens's own evaluator found on the same trace.

Ledger: 38 policies encoded, 1 kept as residue (formulas Ponens's own parser cannot read).
