# Apply Formal Methods Where It Makes Sense

Put ImandraX to work exactly where correctness is high-stakes and machine-checkable — and, once formal methods are in play, use them rigorously end to end.

The 8 policies of the Ponens pack `apply-formal-methods`, as a program of Logical English for LPS: each policy is a law that records a breach, and each of the 8 traces under `sources/traces/` is a scenario. Choose a scenario and press **Run**: the breaches are on the timeline, at the step where each policy failed, and the comment above each scenario says what Ponens's own evaluator found on the same trace.

Ledger: 8 policies encoded, 0 kept as residue (formulas Ponens's own parser cannot read).

The pack restates: Imandra — CodeLogician / SpecLogician formal-reasoning pipeline.
