# Migration twins — other systems' programs in Logical English for LPS

Written by lpsPlus's translators, one directory per source system and one per
program, each with its migration ledger and sources: `daml/` (Daml / Canton
templates), `drools/` (the Drools examples, as world events), `solidity/`
(OpenZeppelin and Circle contracts, with a USDC replay). The timeless twins
(Blawx, LegalRuleML, Miniscript, s(CASP)) are in LE2's examples/migration.

`drools/drl/` holds, beside the Drools twins, the DRL rule bases LPS2 opens
directly (converted to LPS on opening, without Logical English).
