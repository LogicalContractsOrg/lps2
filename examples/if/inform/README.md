# Inform 7 — the Inform stories and test cases these are read from

Eleven Inform 7 programs (`.ni` files): test cases of Inform itself and
examples of its Recipe Book. LPS2 reads the assertions of an Inform program
(what the rooms and things are) and writes a Logical English story on the
library of the folder above. It reports the Inform rules it does not
translate, for you to write again in Logical English. [NOTICE.md](NOTICE.md)
gives their origin and licence.

## Start here
- [IQ Test](IQTest.ni): a Recipe Book example, a case locked with a key.
- [Negated relations](NegatedRP.ni): a short test case about opening things.
- [Implicit connections](ImplicitConnections.ni): the map, both ways from one
  stated connection.

## Try this
1. Open [IQ Test](IQTest.ni). The editor shows the Logical English story
   written from it.
2. Read the diagnostics: each is an Inform rule that you would write again by
   hand.
3. Press **Play** and try the commands the story offers.
4. Compare with [the finished story](../iqtest.le), where those rules were
   written by hand.
