# Logical English — LPS programs written in English

Programs in `the target language is: lps.` — actions, events, fluents and
reactive rules, run by LPS2 (docs/le_lps_surface.md). Each `.le` has its
expected LPS translation kept by LE2, whose `le_lps.pl` translates them
(LE2's testing/fixtures/lps/, checked by its testing/lps_test.pl), and, for five of them, a `.lps` companion for what the English does not reach.
