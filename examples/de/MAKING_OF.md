# Wie die Beispiele dieses Ordners entstanden sind / How the examples in this folder were made

The two programs of this folder were translated from English by an AI agent,
when German Logical English (Logisches Deutsch) was built.

| File | Made by | How |
|---|---|---|
| `feuer.le` | AI agent (Claude Fable 5.2, in Claude Code), 2026-11-25, at Miguel Calejo's request | Translated from `../le/fire_simple.le`. The names after `bekannt als` are those after `known as` in the English program, so that the two programs are read into the same rules. |
| `ueberweisung.le` | Same | Translated from `../le/bank_transfer.le`, in the same way. |
| `README.md` | Same | |

## The record
- `tools/languages_test.pl` checks that each program here is read into the
  same program as its English original, term by term.
